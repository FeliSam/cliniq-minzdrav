# Кардио ДЗМ v1.2 — тренажёр к оценке квалификации кардиолога (ДЗМ, приказ № 827)

**Открыть онлайн:** https://felisam.github.io/cliniq-minzdrav/ · **Офлайн:** скачайте репозиторий и откройте `index.html` в браузере (интернет не нужен).

- **Этап 1:** 100 вопросов из **100 разных** клинических ситуаций (по 1 случайному вопросу из кейса, у каждого своё условие), распределение по разделам, перемешивание, 150 мин, порог 60%. Ранее встречавшиеся на экзаменах кейсы/вопросы выбираются в последнюю очередь.
- **Этап 2:** 2 ситуационные задачи × 12 вопросов (О/Д/Л/В, множественный выбор), 40 мин, порог 60%.
- **Банк:** 106 кейсов × 7 вопросов = 742 вопроса · 30 задач (360 вопросов) · 37 КР · демо Кадрового центра · банк ФМЗА (неофициальная копия).
- **Режимы:** тренировка (кейс целиком), повторение ошибок (SM-2), статистика по КР, план на 30 дней, напоминания (.ics).
- Прогресс хранится в браузере (localStorage); перенос — «Настройки → Экспорт/Импорт JSON».

Структура: `index.html` · `css/` · `js/app.js` · `data/*.js` · `screens/` · `README.txt` (FR/RU).

Предыдущая версия (ClinIQ • Минздрав РФ Exam Hub) сохранена в истории репозитория.

> Кейсы и задачи составлены с помощью ИИ по действующим КР Минздрава России и требуют экспертной проверки; приоритет — у официального текста КР (cr.minzdrav.gov.ru).
